Hello, I'm Rojox

I am a Mexican-born, Chile-based software engineer and independent builder. I like understanding how things work, finding the part everyone forgot to document, and then building a cleaner version with a recognizable point of view.

My work moves between full-stack systems, product architecture, security, Linux, reverse engineering, interactive interfaces, games, and the occasional piece of digital nonsense that somehow becomes a real project.

I am not particularly interested in making another polished dashboard with the personality of an airport terminal.

Things I work on

CATSO — my main independent product, developed under CATSOURAS. It is an experimental social project; the public description is intentionally short.

Linux and hardware — clean-room investigation of the iMac19,2 audio stack, including CS8409/TAS5764L behavior, provenance, and reproducible tests.

Interactive software — old-web interfaces, Canvas experiments, small games, visual systems, and tools built to feel like they came from an alternate timeline.

Engineering foundations — database design, authorization boundaries, migrations, local infrastructure, testing, and all the unglamorous pieces that keep ambitious ideas alive.
